# Research

统一的数据采集、特征、仿真、回测与研究平台。

## 职责

- 采集并保存原始行情、链上事件、基本面和其他研究数据。
- 生成规范化数据集、特征和数据质量报告。
- 提供通用仿真时钟、成本模型、实验管理和指标计算。
- 分别承载 LP、Grid、套利和链上行为等领域研究模型。
- 输出带代码版本、数据集版本和验证结果的策略产物。

## 边界

- 不重复实现生产策略；优先调用 `alpha-lp` 或 `alpha-grid` 的纯策略接口。
- 不保存生产私钥，不签名或广播真实交易。
- 不直接修改产品数据库；研究结果通过版本化产物交付产品。
